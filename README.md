DeliveryCodeDemo

## Project Description

A Python web application demonstrating how to use GitHub Copilot for development. This project showcases:

- **Text Demo** - Command-line application that outputs pub data from Merseyside to stdout
- **Web Demo** - Interactive web application with an interactive map displaying pub locations
- **API Integration** - Fetching and serving real pub data with ratings and real ale counts
- **GitHub Actions** - CI/CD workflows demonstrating automated testing and deployment


The application uses sample data from CAMRA's Good Beer Guide featuring the best pubs in Merseyside, including coordinates, real ale counts, and customer reviews.
